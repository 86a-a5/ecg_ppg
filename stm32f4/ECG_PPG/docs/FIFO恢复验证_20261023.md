# FIFO 恢复修复（2026-10-23）

MAX30102 关闭 FIFO rollover 后，FIFO 满会保留旧数据并丢弃新的转换；溢出计数在 31 饱和。以前仍将积压数据按读取时刻标为最新样本，造成 PPG 时间轴错误。

现在溢出时计数并调用停止、清 FIFO、重新启动的流程，不上传时间不确定的积压数据。恢复失败保留 pending 标志，下次主循环继续重试，避免停在 shutdown。

主循环中的时间戳注释同步更正：只保证批内标称等间隔，批间仍有轮询误差；未声称完成精确同步标定。

验证：`cmake --build build-link` 通过。`python tests/test_fifo_recovery.py` 使用原生 GCC 编译生产函数和模拟寄存器 I/O，覆盖通道解码、溢出丢弃、恢复失败重试、I²C 读失败。

ELF、BIN、HEX 位于 `build-link/`。按用户要求本次仅离线验证，未烧录。完整上下位机报告见 `../../../host_pc/docs/波形链路修复_20261023.md`。

修复前标签 `before-waveform-review-20261023` 对应 `f10f432`；此提交保存了本次检查开始时已有的未提交固件修改。
