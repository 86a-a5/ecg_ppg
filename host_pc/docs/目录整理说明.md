## 使用方式

两个 `.bat` 启动入口保持原位置，窗口和采集功能保持一致。
源码改为 `ecg_ppg` 包结构，路径统一由 `src/ecg_ppg/paths.py` 管理。
从根目录运行 `python run.py gui`、`python run.py unicardio ...`、`python run.py test` 即可，
启动器会配置包搜索路径，无需把工程安装到系统 Python。

完整使用手册已移到 [使用手册.md](使用手册.md)，根目录 README 提供简短导航。
请通过根目录入口启动，不再直接执行整理前那些已移动的根目录 Python 文件。
外部 UniCardio 预训练模型、`.venv`、`.idea`、`.git` 均保留原位。

## 文件保留与校验

原有采集数据没有移动。验证结果、手动备份和旧缓存只做了移动，没有删除文件。
迁移瞬间对 33 个既有文件逐一核对 SHA-256，移动前后内容一致。
清单保存在 `outputs/folder_organization_manifest.json`；后续运行测试会正常更新验证报告和图片。
验证输出、旧备份、运行环境和个人数据继续由 Git 排除。

## 回到整理前

关闭上位机并保存当前代码修改后，在项目根目录执行：

```powershell
git switch feature/unicardio-bp
```

该分支保留已接入 UniCardio、尚未整理目录的版本；`main` 是更早的采集基线。
返回整理后的版本：

```powershell
git switch refactor/project-layout
```

Git 切换代码时不会搬动或删除 `records`、`outputs`、`archive` 中的数据。
使用旧版本说明查找验证结果时，应到现在的 `outputs` 下寻找。
