# ECG / PPG 采集联调说明（2026-10-16）

> 下文保留 2026-10-16 的实机联调记录。2026-10-19 已进一步更新显示滤波和绘图，
> 当前参数及离线回放结果见 [显示滤波优化说明](显示滤波优化说明.md)。历史采集文件未覆盖。

本轮只处理采集、传输、分路显示和用户要求的 ECG 50 Hz 陷波，没有加入血压推理。

**当前启动方式。**

双击项目根目录 start_com13.bat，自动打开上位机并连接 COM13、115200、8N1。
若串口号变化，双击原有 start_gui.bat，选择实际端口后连接。
同一个串口只能被一个程序占用，已打开实时窗口时先在该窗口操作。

界面从上到下显示 ECG、IR PPG、RED PPG 三条曲线。左侧“ECG 50 Hz 陷波（显示）”
默认勾选，取消勾选可立即查看原始 ECG。ECG 的纵轴为 AD8232 输出相对偏置的 mV，
不是已经折算前端增益后的电极输入电压。

**本轮修复的内容。**

| 位置 | 修复 |
|---|---|
| 下位机 USART2 | 使能 USART2 IRQ 并接入 HAL_UART_IRQHandler，让普通 TX DMA 能完成回调并持续发送 |
| 下位机发送队列 | 使用 4096 字节、编译期长度检查、局部组帧数组；序号在入队临界区分配，顺序与入队一致 |
| 下位机发送状态 | DMA 启动前记录忙状态和长度；HAL_BUSY 保留队列重试；发送错误不再直接丢弃队列字节 |
| PPG 采集 | 先停止转换并清 FIFO 再启动；一次连续读取 FIFO 快照中的样本对，最多 32 对 |
| 时间戳 | TIM5 在采集前启动；PPG 在 FIFO 连续读取前打点并倒推各样本时刻 |
| 时钟 | 优先使用板载 25 MHz HSE；TIM2/TIM5 按实际 APB 定时器时钟分频。没有 HSE 时回退 HSI |
| CubeMX | 同步 200 Hz 周期、TIM5 最大周期、USART2、TX DMA 和中断配置 |
| 上位机解析 | 允许饱和 PPG 帧；检查 ECG 12 位范围；修复跨回绕点的 ECG/旧 PPG 交错展开 |
| 上位机绘图 | IR 读取协议第二通道，RED 读取第一通道；ECG 正确换算 mV；横轴使用实际时间戳 |
| 上位机状态 | 重连清空显示状态；分别判断 ECG/PPG 是否停止；采样率按时间跨度计算 |
| ECG 显示 | 新增可开关的 50 Hz 二阶 IIR 陷波，Q=20；采样中断或重连后重置滤波状态 |

原有目录已包含部分队列和暂存区修复，本轮保留并继续完善，没有回退已有功能。

**为什么改用板载晶振。**

直接以电脑计时，旧 HSI 配置在 10.002 秒中收到 ECG 1903 点、PPG 1003 对；
按设备时间戳却显示 ECG 200 Hz、PPG 105.43 Hz，暴露 MCU 时基偏慢。
切到板载晶振后，实测约 ECG 200.0 Hz、PPG 100.2 Hz。
ST-Link 读取 RCC_CFGR=0x00000005，确认系统已选择 HSE。

本板已经过实测，晶振按工程配置的 25 MHz 使用。若迁移到其他频率晶振的板子，
应相应修改 HSE_VALUE 与 CubeMX 配置；无晶振的 HSI 回退路径没有本轮的实机精度保证。

**50 Hz 陷波怎样使用。**

滤波器只处理显示缓冲，ECG ADC 原始数据及 CSV 中的 ecg_raw、ecg_processed 保持未陷波。
IR 与 RED 的交流曲线分别由各自原始值减去一阶直流估计得到，记录仍保留原始量级。

50 Hz 陷波采用状态连续的二阶 IIR，采样率 200 Hz，Q=20，对应 -3 dB 带宽约 2.5 Hz；
这类滤波器的频率与 Q 定义可对照 [SciPy 官方 iirnotch 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.iirnotch.html)。
回归检查覆盖 50 Hz 抑制、1.2 Hz 信号幅度保留、直流初始化及时间断点后的状态重置。

陷波不会恢复 ADC 饱和时已经丢失的波形细节。界面的“接近电源轨”提示基于原始 ADC，
不会因显示曲线被滤波而隐藏。是否取得清晰心电形态，应结合实际曲线与这个提示判断。

**实机验证证据。**

- outputs/link_validation/report.json：真实 COM13 采样率、帧数、坏帧、序号丢帧、时间步长、陷波衰减。
- outputs/link_validation/live_capture.csv：真实原始采集数据；ECG 与 PPG 各自有独立时间列。
- outputs/link_validation/live_waveforms.png：实际 GUI 绘图对象导出的三路波形。
- outputs/link_validation/before_notch/：板载晶振配置下，加入陷波前的一轮记录。
- outputs/link_validation/initial_hsi/：定位时基偏差时的首轮记录。

本轮已通过 ARM 编译、ST-Link 写入校验与 8 项协议/GUI/滤波回归检查。
报告中的 passed 表示采集传输检查通过，不代表所有传感器输入都具有合格的生理波形。
序号丢帧为 0 也不能单独证明传感器 FIFO 在组帧前绝对没有丢样；本轮另检查过 MCU 统计量。

需要再次做自动实测时，可在项目根目录运行：

~~~powershell
python run.py verify --port COM13 --seconds 30 --output outputs/link_validation --keep-open
~~~

该命令通过真实 GUI 接收线程采集，保存上述证据后保持实时窗口。运行前关闭其他占用 COM13 的程序。

回归检查命令：

~~~powershell
python -m unittest test_acquisition_link -v
~~~

**固件位置与接线。**

本轮烧录的文件在 ../stm32f4/ECG_PPG/build-link/ECG_PPG.elf，另生成了同目录 .bin、.hex。
首次烧录前已备份原板完整 Flash 到 build-link/previous_flash.bin。

| 信号 | STM32 引脚 |
|---|---|
| AD8232 OUTPUT | PA0 / ADC1_IN0 |
| MAX30102 SCL | PB6 |
| MAX30102 SDA | PB7 |
| USART2 TX → USB-TTL RX | PA2 |
| USART2 RX ← USB-TTL TX（当前无接收命令） | PA3 |
| 模块地与 USB-TTL 地 | 共用 GND |

12 字节协议保持兼容：类型 01 为 ECG，02 为 PPG；PPG 第一值是 RED、第二值是 IR，
两者在下位机右移 2 位上传，上位机左移 2 位恢复量级，最低两位不能恢复。
两路共用 TIM5 计时基准，但 PPG 时间戳仍由 FIFO 快照估计，尚未完成精确同步误差标定。
