# PPG 极性显示修正（2026-10-28）

## 原因与修正范围

正式入口 `start_gui.bat` → `launch_gui.py` → `ecg_ppg.gui.serial_ecg_ppg_gui` 原先直接显示光强交流分量，没有应用极性转换。目录中的其他旧 BLE 脚本虽比较过正、负峰的心率检出结果，但不是本入口的绘图控制。

MAX30102 原始值代表接收光强，其收缩期主波通常向下；`raw − DC` 和带通滤波会保留这个方向。因此原来的向下主波不是时间倒序造成的。参考 [ADI 对 PPG AFE 输出极性的说明](https://ez.analog.com/optical_sensing/a/documents/DO19503/why-is-the-ppg-waveform-observed-thru-afes-differ-slightly-from-the-ppg-waveform-found-in-medical-texts)。

本次增加 `gui/ppg_polarity.py`，在采集页绘图末端应用 ×−1/×+1：

- 默认自动模式，在信号不足时使用 MAX30102 反相预设。
- 至少约4秒连续数据、至少4个周期，并通过光强、幅度、偏斜和周期间隔约束后，可自动判定并锁定。近正弦或不规则波形不能可靠判方向，保留预设并显示“待判定”。
- 可手动选择“反相（MAX30102）”或“原极性（光强）”。重新选择自动或重新连接会清除旧判定。
- IR 判定方向同时用于 IR/RED；滤波打开、关闭均适用。

符号转换不重置 IIR、不改变时间戳或滤波参数，不会把负峰移动到其他时刻。
原始记录、模型原始缓存、CSV数值、DC光强和采样帧保持原值。
模型及离线特征检测仍有独立处理入口，本次没有把显示开关隐式传播到它们；训练数据的极性约定需单独核对。

自动方法用于显示方向辅助判断，不能据此医学性地认定任意尖峰或小波动就是收缩峰、重搏切迹；也不使用固定 R峰后0.15–0.35秒作为所有人的判据。与论文采用相同的向上显示约定，不意味着两种传感器和接触条件产生的波形细节必然完全相同。

## 使用

重新打开 `start_gui.bat`。在左侧“信号状态→PPG显示极性”选择：

1. 自动（MAX30102预设）：默认。
2. 反相（MAX30102）：明确按当前模块的光强反相关系显示。
3. 原极性（光强）：与传感器原始方向作对照。

## 验证

完整测试共35项：34项通过；真实 UniCardio 权重测试按原有开关跳过1项。
新增验证覆盖正/负周期脉搏、平线、正弦、随机噪声、单个尖峰、接触突变、时间断点、判定锁定/复位，以及真实 Tk/Matplotlib 的模式切换。

GUI回归确认：

- 负向光强脉搏显示为向上主波；原谷的位置就是反相后的峰位置。
- 三种模式、滤波开关切换均保持时间坐标递增，不倒序、不调整样本间隔。
- IR/RED 同步翻转；原始记录、模型缓存和时间戳逐点不变。
- 已通过实际离线窗口操作检查下拉选项和图形方向。
