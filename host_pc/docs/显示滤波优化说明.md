# ECG / PPG 显示滤波优化（2026-10-19）

本次修改的是 `host_pc/serial_ecg_ppg_gui.py` 串口上位机。参考 MFC 工程的连续滤波状态、轻度显示平滑、稳定缩放和整帧呈现思路；参数按本项目实际的 ECG 200 Hz / PPG 100 Hz 重新设计，未直接复制 MFC 的 250 Hz 参数。

## 当前处理链

| 通道 | 实际采样率 | 仅用于显示的 IIR 滤波 |
| --- | --- | --- |
| ECG | 200 Hz | 0.5 Hz 一阶高通 → 50 Hz 二阶陷波（Q=30）→ 40 Hz 二阶 Butterworth 低通 |
| PPG IR | 100 Hz | 0.5 Hz 一阶高通 → 8 Hz 二阶 Butterworth 低通 |
| PPG RED | 100 Hz | 与 IR 相同的参数，使用独立滤波状态 |

PPG 的 50 Hz 恰好位于奈奎斯特频率，不应套用 ECG 的 50 Hz IIR 陷波设计；8 Hz 低通用于减弱数字波形里的高频干扰。采样前已混叠到低频的干扰仍需在传感器或采样链处理。

三条滤波后的曲线均增加 5 点、二次多项式 Savitzky-Golay 轻度平滑。输出对应窗口中心采样点，保留其原始时间戳；因此此步骤增加 ECG 10 ms / PPG 20 ms 的显示等待时间。IIR 滤波自身也会产生与频率相关的相位延迟。

滤波状态跨接收批次持续保留；重连、时间不递增或超过三个采样周期的间断会重置。绘图在时间断点处断线，避免把缺失数据连成斜线。PPG 巨大的直流阶跃会重新初始化显示滤波，减轻放上或移开手指时的滤波拖尾。

## 显示与操作

- 启动方式保留：双击 `start_gui.bat`，或用 `start_com13.bat` 自动连接 COM13。已经运行的 Python 上位机需要重启，标题包含“滤波优化版”。串口配置仍为 115200 / 8N1，无需重烧 MCU。
- 左侧 ECG、PPG 两个滤波开关默认开启。关闭 ECG 滤波可看原始 ADC 换算波形；关闭 PPG 滤波可看原先仅减直流、未做低通的交流分量。两种模式使用同一套实际采集时间轴。
- 纵轴采用带余量的 1-2-5 量程，峰值变大时及时扩大，持续变小三秒后才缩小。使用实际峰值而非百分位裁掉狭窄的 R 峰；暂停采集时仅重绘不会改变量程。
- 保留 6 秒滚动显示和三路分图。正常情况下约 20 帧/秒，使用 Matplotlib 背景缓存/blit 更新曲线；改量程、改滤波开关或窗口缩放时重建背景。
- 修正静态图片导出，使缓存绘图的曲线也能正常保存在 `verify_live_link.py` 的截图里。

ECG 的 mV 是 AD8232 模块输出相对 ADC 偏置的电压，未除以模拟前端增益；PPG 的 AC 单位仍是 ADC 码值。

## 原始记录与血压算法

录制器仍直接接收解析后的原始 ECG、IR、RED 数值及 TIM5 同源时间戳。未修改协议、录制器、CSV 列结构、`ecg_ppg_signal.py`、特征提取或血压推理代码。质量检查仍使用原始 ADC 和原有直流/交流数据，显示平滑不会隐藏电源轨报警。

**不能用这三条显示曲线的峰间距直接计算 PAT/PTT。** 两路显示滤波延迟不同。后续血压特征计算应继续从原始同步记录开始，并单独验证算法所用的零相位预处理或延迟补偿。

## 验证

- `python -m unittest discover -v`：15 项测试通过，覆盖协议、回绕、ECG/PPG 各自频率响应、与 SciPy 独立设计结果的数值对照、直流初始化、中断重置、平滑时间戳、狭窄峰保留、量程迟滞、实际 Tk/Matplotlib 绘图，以及原始录制保持不变。
- 合成信号图：`outputs/display_validation/synthetic_waveforms.png`。这是合成 ECG/PPG，不是人体实测结果。
- 历史实测回放：读取原有 `outputs/link_validation/live_capture.csv`，共 6008 个 ECG 点、3011 对 PPG。新流程的 ECG 49–51 Hz 频带能量较原始数据降低约 **22.4 dB**；该数值包含高通、陷波和低通的共同效果，按启动两秒后的整段记录与 Hann 窗计算。
- 历史回放图和来源哈希：`outputs/display_validation/replayed_waveforms.png`、`outputs/display_validation/replay_report.json`。原有 `link_validation` 内容保持原样；本轮没有重新打开硬件串口采集。

历史记录中约 **10.2%** 的 ECG 原始值处于 ADC 电源轨附近（满量程两端约 3% 内），并存在 PPG 直流变化。工频衰减和显示变平滑不代表这些信号缺陷已恢复，仍需重新检查电极接触、手指固定和模拟前端，采一段稳定数据确认效果。

可自行回放现有同步 CSV：

```powershell
python run.py replay outputs/link_validation/live_capture.csv --output outputs/display_validation
```
